# Optional local QVAC chat

Accepted 2026-11-20. The signed-in owner can choose **Routstr → Local AI · QVAC** for a separate text-only question. This is neither a Routstr model selection nor the Teams provider. No shared history, wallet, tools, attachments, automatic escalation, or model-directed actions. The authenticated local endpoint streams text over the existing same-origin transport. It never calls a remote provider. Closing the dialog clears the visible text.

The opt-in deployment input `install_qvac` installs the official QVAC 0.24.0 SDK, a pinned Python 3.14 x64 dependency set, and one SHA-256-verified Llama 3.2 1B Q4_0 GGUF. No global Python install, public listener, network permission during inference, or idle model process. One request at a time via a group-protected Unix socket; systemd assigns the worker a separate transient identity and bounds CPU priority, RAM, plaintext lifetime and runtime. Disabled hosts get a local-only unavailable message. Existing installations are never silently upgraded or overwritten.

The installer measures free space and preserves a 2 GiB deploy reserve. Archives use tmpfs; smoke-test failure removes only the new install. To disable a healthy installation, stop and disable `continuum-qvac.socket`; leave the files intact. Roll back the application to the previous merged tag through the usual deploy workflow. Re-enable the socket only on a compatible release.

Benchmark: identical verified GGUF (`fa0390e7…a8be8`), two CPU threads, 2048 context, greedy sampling, 48-token cap, same single-sentence rainbow prompt, three sequential requests per engine. Measured from each local request to first nonblank text and completion, after explicit model load. [QVAC run](https://github.com/ChiefmonkeyArt/torii-quest/actions/runs/44726782698): 5.701/15.324, 6.657/13.413, 5.499/11.548 seconds. [Ollama run](https://github.com/ChiefmonkeyArt/torii-quest/actions/runs/44727180488): 19.321/36.222, 0.518/16.494, 0.513/14.010. Repeated prompt caching and VPS load affect timings; this is not a browser latency guarantee. The production worker deliberately loads on demand.

[Footprint test](https://github.com/ChiefmonkeyArt/torii-quest/actions/runs/44727530630): approximately 2.55 GB installed; 2.92 GB filesystem space remained. No existing app, model or recovery data was deleted. See [QVAC platform documentation](https://docs.qvac.tether.io/sdk/system-requirements/) and the [model file](https://huggingface.co/bartowski/Llama-3.2-1B-Instruct-GGUF/blob/main/Llama-3.2-1B-Instruct-Q4_0.gguf).
